# Portofolio Pribadi - Wulan Zahra Annisa

Website ini merupakan portofolio pribadi bertema **elegan feminin** dengan nuansa **pink dan gold**.

## ✨ Fitur Utama
- ✅ **3 Halaman**: Home, Portfolio, dan Contact
- 💅 **Desain Responsif**: Tampilan tetap rapi di laptop maupun smartphone
- 🌸 **Warna Elegan**: Kombinasi pink pastel, putih lembut, dan sentuhan gold
- 📊 **Tabel Data Portofolio**: Menampilkan daftar proyek
- 📩 **Form Request Project**: Klien dapat mengirimkan permintaan kerja sama

---

## 💻 Teknologi
- HTML5  
- CSS3 (tanpa framework, full manual)  
- Konsep **Responsive Web Design (RWD)** dengan media query dan grid

---
## 📱 Responsivitas
Website ini mendukung berbagai ukuran layar, termasuk mobile, tablet, dan desktop, dengan navigasi yang konsisten di setiap halaman.
